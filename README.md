# Financial Analytics & Cash Flow Intelligence Dashboard

An end-to-end analytics project built using **PostgreSQL, Python, and Power BI** to analyze customer payment behavior, collection performance, financial risk, and cash flow forecasting.

## Architecture

```text
Python Data Generation
          ↓
      PostgreSQL
          ↓
     SQL Analysis
          ↓
      SQL Views
          ↓
       Power BI
          ↓
 Interactive Dashboards
```

## Tech Stack

* PostgreSQL
* Power BI
* Python
* SQL
* Git & GitHub

## Key Features

* Executive KPI Dashboard
* Customer Risk Analysis
* Collection Performance Tracking
* Cash Flow Forecasting
* DSO & Collection Efficiency Analysis

## Dashboard Pages

1. Executive Overview
2. Customer Risk Analysis
3. Collection Performance
4. Cash Flow & Forecasting

## Skills Demonstrated

* SQL & Data Modeling
* Business Intelligence
* Dashboard Development
* Financial Analytics
* Forecasting & Risk Analysis
* Data Visualization
